# GG-Training

Lern-Website zur Vorbereitung auf die Kurzarbeit in **Politik und Gesellschaft** (FOS 12, Bayern).

Themen: Grundgesetz, wehrhafte Demokratie, Gewaltenteilung, Grundrechte, AfD-Verbotsverfahren und das politische System der Bundesrepublik.

👉 **Live-Seite:** https://luisswz.github.io/gg-training/

## Hinweise

- Die Seite läuft komplett im Browser – kein Login, kein Server, keine Datenübertragung.
- **Dein Fortschritt bleibt nur auf deinem Gerät** (im Browser gespeichert). Auf einem anderen Gerät oder in einem anderen Browser fängst du von vorne an. Wenn du die Browserdaten löschst, ist der Fortschritt weg.
- Podcast und Erklärvideo erscheinen automatisch, sobald sie hochgeladen sind.
